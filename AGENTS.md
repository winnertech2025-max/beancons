# Happy Farm local instructions

Before any implementation, review, or QA work on Happy Farm, read `.agents/skills/happy-farm-quality/SKILL.md` in full and follow it. For a new quality-overhaul phase, also read `docs/MASTER-QUALITY-OVERHAUL.md`.

Every minigame completion requires the browser QA checklist and an evidence-backed update to `docs/QA-REPORT.md`; a successful build is not sufficient.
